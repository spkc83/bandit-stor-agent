# Architecture Decisions

## ADR-001: Contextual Bandit MVP

Decision: The MVP uses a contextual bandit formulation.

Rationale:

- The target production setting is offline training with immediate reward feedback.
- Open Bandit Dataset fits contextual bandit learning.
- Sequential RL requires trajectories, state transitions, delayed rewards, and more complex OPE.

Consequence:

- Actor loss uses doubly robust contextual bandit objective.
- No Bellman targets or Q-learning in MVP.

## ADR-002: PPO Excluded as Default

Decision: PPO is excluded from the MVP.

Rationale:

- PPO is on-policy.
- Static logged recommender data was generated by a historical behavior policy, not by the actor's previous version.
- Offline policy learning constrains against behavior support rather than PPO old-policy ratios.

Consequence:

- The MVP uses DR objective, alpha divergence, and support penalties.

## ADR-003: Open Bandit Dataset as Default

Decision: Open Bandit Dataset is the default training dataset.

Rationale:

- It provides real logged bandit feedback.
- It includes logged action, reward, context, position, and propensity score.
- It aligns with IPS, SNIPS, and DR evaluation.

Consequence:

- Synthetic generation is not used for training.
- Tiny fixture data is allowed only for tests.

## ADR-004: Sparsemax Actor

Decision: Actor uses Sparsemax instead of dense softmax.

Rationale:

- Recommender action spaces are large.
- Dense softmax assigns mass to too many irrelevant or unsupported candidates.
- Sparsemax produces exact zero probabilities and aligns with Tsallis q=2 entropy.

Consequence:

- Actor support size is a first-class diagnostic.
- Need careful handling when support becomes too small.

## ADR-005: Tsallis q=2 Entropy

Decision: Replace Shannon entropy with Tsallis q=2 entropy.

Rationale:

- Tsallis q=2 supports sparse policy geometry.
- It encourages controlled multi-item support rather than dense exploration.

Consequence:

- Entropy diagnostic is `H2 = 1 - sum(pi^2)`.

## ADR-006: Alpha-Divergence Support Constraint

Decision: Penalize `D_alpha(pi_theta || mu_hat)`.

Rationale:

- Offline policies require proximity to behavior support.
- Alpha greater than 1 strongly penalizes actor mass where behavior support is weak.

Consequence:

- Need behavior probabilities over candidate set or an approximation.
- Support diagnostics are mandatory.

## ADR-007: Doubly Robust Objective

Decision: Actor maximizes DR policy value.

Rationale:

- Direct reward model alone can be biased.
- IPS alone can have high variance.
- DR combines reward model estimate with propensity-weighted residual correction.

Consequence:

- Reward model is required.
- Logged propensity is required for the residual term.
